## CUET_Sntx_Srfrs at BLP-2025 Task 1:Combining Hierarchical Classification and Ensemble Learning for Bengali Hate Speech Detection

This repository contains the code and resources of our system submitted to BLP-2025 Task 1: Bangla Multi-task Hate Speech Identification.

Our approach combines classical machine learning, hierarchical classification, and majority-vote ensembles to detect hate type, severity, and target groups in Bengali YouTube comments.
